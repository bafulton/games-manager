# Security reporting

This is an early alpha. Use the latest release and read migration notes.
The OIDC UI is not implemented; `spec.owner` does not enforce authorization.
See [the trust model](docs/authentication.md).

Use GitHub's [private vulnerability reporting](https://github.com/bafulton/games-manager/security/advisories/new)
when enabled. If unavailable, open an issue requesting a private reporting
channel without exploit details, credentials or private cluster information.
Ordinary non-sensitive bugs can use public issues.

Include affected versions, reproduction steps, expected/actual behavior
and impact. Redact credentials and identifying cluster configuration.
No response-time commitment is currently offered.
